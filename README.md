# Todo App

A simple todo application built with Python, Flask, SQLite, and Docker.

## Features
- Add tasks
- Mark tasks complete
- Delete tasks
- Persistent storage using SQLite
- Dockerized setup

## Tech Stack
- Python
- Flask
- SQLite
- Docker
- Docker Compose

## Run Locally
```bash
docker-compose up --build
```

Open:
http://localhost:5000
